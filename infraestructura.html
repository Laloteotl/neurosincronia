INFRAESTRUCTURA

Las herramientas correctas reducen la fricción cognitiva.
Hardware mínimo viable
Un dispositivo que funcione bien vale más que dos que funcionan mal.
RAM mínima para trabajo cognitivo: 8GB. Con menos, el sistema operativo compite con tu cerebro.
SSD sobre HDD siempre — la velocidad de carga afecta la continuidad de atención.
Pantalla externa si trabajas más de 4 horas: reduce carga visual y mejora postura.
Antes de comprar hardware nuevo: limpia el actual. Reinstala el sistema si tiene más de 2 años sin formato.
Stack de herramientas esencial
Editor de texto: VS Code (gratuito) — sirve para código, notas y markdown.
Notas y conocimiento: Obsidian (gratuito, local-first, sin suscripción).
Gestión de tareas: Todoist free o simplemente un archivo .txt con fecha.
Comunicación: mantén el mínimo posible de apps activas — cada una es un vector de distracción.
Bloqueadores: Freedom, Cold Turkey o simplemente el modo "No molestar" del sistema.
Más herramientas no es más productividad. El cerebro neurodivergente sufre más con el cambio de contexto entre apps.
Protección de trabajo
Regla 3-2-1: 3 copias, 2 medios distintos, 1 fuera del hogar (nube).
Google Drive o Mega (gratuitos) para backup automático de documentos críticos.
GitHub para código — commit al final de cada sesión de trabajo.
Perder trabajo por no hacer backup es un golpe cognitivo y emocional severo. No lo arriesgues.
Automatiza el backup. No dependas de recordarlo.
Higiene del entorno de trabajo
Escritorio vacío: solo lo que usas hoy. El desorden visual consume atención.
Notificaciones: apaga todas excepto las críticas — define cuáles son críticas ahora mismo.
Pestañas: máximo 5 abiertas durante trabajo. Usa marcadores en lugar de pestañas abiertas.
Modo oscuro siempre — reduce fatiga visual en sesiones largas.
Tu entorno digital es tu ambiente de trabajo. Trátalo con el mismo cuidado que un espacio físico.
