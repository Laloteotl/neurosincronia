02 — CRISIS COGNITIVA

Protocolos inmediatos para bloqueo, ansiedad, shutdown y burnout.

BLOQUEO

  1. Detente.
  2. Haz una acción física mínima.
  3. Escribe una palabra sobre la tarea.
  4. Ejecuta el primer micro paso.

ANSIEDAD

  1. Respira 4-7-8 tres veces.
  2. Cambia de espacio físico.
  3. Nombra el peor escenario.
  4. Evalúa con lógica.

SHUTDOWN

  1. Apaga pantallas.
  2. 15 minutos de silencio.
  3. Agua fría.
  4. No decidas nada.

BURNOUT

  1. Detén todo lo no crítico.
  2. Duerme.
  3. Come.
  4. Recupera energía.
